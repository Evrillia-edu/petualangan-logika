# Petualangan Logika

Game edukasi logika pemrograman untuk anak-anak (maze + blok perintah: Maju, Kiri, Kanan, Ulangi/loop).

## Menjalankan lokal
Cukup buka `index.html` langsung di browser, atau pakai extension "Live Server" di VS Code.

## Deploy ke Vercel
Lihat langkah-langkah di bawah (bisa lewat CLI atau lewat GitHub + dashboard Vercel).
